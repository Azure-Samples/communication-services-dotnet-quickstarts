About Transfer

Transfer an active call to another number or participant. You can perform a blind transfer (no transferee) or an attended transfer (specify which participant to transfer).

Get from active call
Target phone number in E.164 format
Full ACS user identifier

Attended Transfer (Optional)

Attended Transfer: Specify which participant in the call should be transferred. Leave empty for blind transfer (transfer the entire call).

Participant to transfer
Participant to transfer

About Hang Up

Terminate an active call connection.

Get from active call
When checked, terminates the call for all participants. When unchecked, only disconnects your connection.

Media Playback Testing

About Play Audio

  • Play Audio: Plays to a specific participant (requires target)
  • Play to All: Broadcasts audio to all participants in the call
  • File Source: Play from URL or local file
  • Text Source: Text-to-Speech (TTS)
  • SSML Source: Speech Synthesis Markup Language

Target Participant (For Play Audio Only)

Note: "Play Audio" requires a specific target participant. If you want to broadcast to everyone, use "Play to All" button instead.

E.164 format (e.g., +15551234567)
Full ACS user identifier
WAV file recommended

Participant Management Testing

About Add Participant

Add a new participant to an active call. Supports both PSTN phone numbers and ACS users.

E.164 format (e.g., +18005551234)
Format: 8:acs:resource-id_user-id
How long to wait for participant to answer (default: 30)

About Remove Participant

Remove a participant from the call. Supports both PSTN and ACS participants.

E.164 format (e.g., +18005551234)
Format: 8:acs:resource-id_user-id

About Mute Participant

Mute a participant's audio in the call. Supports both PSTN and ACS participants.

E.164 format (e.g., +18005551234)
Format: 8:acs:resource-id_user-id

About List Participants

Get all participants in a call.
